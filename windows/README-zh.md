# 67 - 原生弹窗秀 (v3.1)

两个程序：

| 程序 | 作用 |
| --- | --- |
| **`67.exe`** | 双击开演（弹窗 → 全屏大 67） |
| **`67-Settings.exe`** | 可视化设置：滑杆调时间/数量/音量，右边实时预览布局 + 时间轴 |
| **`linux-mac/67.py`** | Linux / macOS 客户端（零依赖 Python 3 + tkinter） |

设置保存到同目录的 `67.ini`，`67.exe` 启动时自动读取（命令行参数优先级更高）。

GitHub 仓库：<https://github.com/Xiaowu-0916/67-popup-show>（README 中英双语，仓库简介末尾是一串 67）

## 开演流程

1. **炸开一堆原生窗口**：约 18-20 个真·Win32 窗口连环弹出（默认覆盖屏幕 75%），
   全屏随机撒点（随机大小/随机重叠/允许轻微出屏），但保证 4×4 共 16 个区域每区都有窗口 ——
   随机观感、全屏无空角；窗口里的 `67` 填满窗口约 90%，配色/字体/边框/贴纸/表情各不相同；
2. **同时开始放歌**：`audio\67.m4a`（抖音音乐《67》/ DJ R4）**从音频最开头播放**；
3. **全屏特效**：彩虹放射光、飘落的 67 雨、彩纸、扩散光环、霓虹描边，覆盖整块屏幕（含任务栏区域）；
4. 默认停留 **6 秒**后窗口逐个缩小淡出关闭（音乐**继续播**）；
5. 最后一个**全屏大 67**（铺满整屏，特效层继续叠在它上面）；
6. **你手动关掉大 67 的那一刻，音乐才停止**（右上角 ×、`Esc`、右键菜单、双击都能关）。

## 每台设备都全屏（DPI 修复）

程序启动时会：

1. 声明 **per-monitor-v2 DPI 感知**（失败则退回 per-monitor / system 级）；
2. 用 `EnumDisplaySettings` 读取真实显示模式，与 `Screen.Bounds` 交叉核对，
   发现拿到的是被虚拟化（缩小）的桌面时自动改用真实分辨率；
3. 仍不对时可手动兜底：`67.exe --area 2560x1440`，或 `--no-dpi` 关闭感知对比效果。

实测：本机实为 **1920×1080 @125% 缩放**，旧版只看到 1536×816（于是窗口挤在左上角），
修复后正确读到 1920×1080 并整屏铺满。

## Linux / macOS 客户端

```bash
cd linux-mac
chmod +x 67.sh 67.command 67.py     # 首次
./67.sh                             # Linux
./67.command                        # macOS（或访达双击）
```

同一套行为：随机铺满的原生窗口 → 全屏特效 → 全屏大 67，关掉大 67 时音乐停止。
播放器自动在 `afplay`(macOS) / `mpv` / `ffplay` / `mplayer` / `mpg123` / `paplay` 中选择。

窗口里随机出现：彩虹渐变 67、描边 67、霓虹 67、多个 67 叠加、贴纸（星星/闪电/爱心/圆环/闪光）、
卡通表情（大小眼笑脸、墨镜款）、倾斜、颜色持续流转。

全部是 Windows 原生窗口（WinForms / GDI+），没有 HTML、没有浏览器、不联网、不写注册表、不常驻。

## 可视化设置（67-Settings.exe）

右侧预览用的是**和正式程序同一套布局引擎**，所以看到的窗口数量、覆盖率、大小就是真实效果；
底部时间轴把「延迟 → 弹出 → 停留 → 关闭 → 大 67」各阶段时长画成条形，并标出
「音乐从第几秒开始播、什么时候停」。

| 可调项 | 范围 |
| --- | --- |
| 覆盖屏幕比例 | 40% - 95% |
| 弹窗停留时间 | 0.5 - 60 秒 |
| 窗口数量上限 | 5 - 120 |
| 窗口尺寸倍率 | 0.5 - 2.5 倍 |
| 大 67 停留时间 | 0 - 3600 秒（0 = 只能手动关） |
| 音量 | 0 - 100% |
| 音乐起始位置 | 0 - 300 秒 |
| 开关 | 全屏特效 / 窗口漂移 / 播放音乐 / 大 67 全屏 |

按钮：`保存`、`保存并试一次`（立刻启动 67.exe）、`恢复默认`。

## 命令行参数（可选，覆盖 67.ini）

```
67.exe --coverage 0.75    目标覆盖率（0.20 - 0.95）
       --min 10 --max 60  窗口数量下限/上限
       --hold 6.0         弹窗停留秒数
       --final 300        大 67 自动关闭秒数（0 = 不自动关）
       --window-scale 1.2 窗口尺寸倍率
       --volume 0.8       音量         --audio-start 0  从第几秒开始播
       --audio <文件>     换音频       --no-audio       静音
       --no-fx            关全屏特效   --no-wobble      关窗口漂移
       --no-final-fullscreen          大 67 不全屏（留边）
       --all-screens      铺满所有显示器
       --seed 12345       固定布局     --config <file>  指定配置文件
       --log run.txt      执行日志
       --dump-layout a.png / --dump-finale a.png / --dump-fx a.png   离屏导出预览图
```

## 重新编译

双击 `build.cmd`（需要 Win10/11 自带的 .NET Framework 4.x，含 WPF 程序集），会同时重新生成
`67.exe` 和 `67-Settings.exe`。

## 验证记录（本机实测）

- 1536×816 工作区：实测 **18-19 个窗口 / 覆盖率 75.7% - 77.6%**（目标 75%）。
- 音频：`opened (231.0s)` → 从 0 秒开始播 → 弹窗关闭时**不停** → `giant: closing (auto-close-timer)`
  → `audio: stop requested`，即「关掉大 67 才停」。
- 大 67 尺寸：`1536x864`（整屏，含任务栏），特效层叠在其上（`SetWindowPos(HWND_TOPMOST)`）。
- 特效层：逐像素 alpha（已做预乘修正，颜色不再发白），鼠标穿透、不抢焦点。
- 完整流程退出码 **0**，无残留进程；`Esc` 中断测试同样退出码 0 且音乐立即停止。
- 特效峰值约占 0.9-1.1 个核心（8 核机器约 12%），持续约 8 秒。

## 注意事项

- 大 67 是全屏 + 置顶的，默认 5 分钟后自动关闭；随时可以 `Esc` / 右上角 `×` / 右键关掉。
- 若 Windows「智能应用控制」拦截（未签名 exe 会送云端信誉查询，网络异常时会误拦），
  重新双击 `build.cmd` 生成新的 exe 再运行即可（哈希变化会重新判定）。
- `audio\67.m4a` 取自你提供的抖音音乐页，仅本地使用；删掉它程序会自动静音运行。
